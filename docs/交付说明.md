## 五、如何运行

1. **离线演示**（零依赖）：浏览器直接打开 `index.html`；
2. **完整功能**：
   ```bash
   pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
   copy .env.example .env      # 填入 DASHSCOPE_API_KEY（可选）
   start.bat                   # 或 python backend/server.py
   ```
   浏览器打开 `index.html`（或 `http://127.0.0.1:8765`），默认 API 地址 `http://127.0.0.1:8765`；
3. **测试**：`python -m pytest tests -q`；
4. **MCP stdio**：`python backend/mcp_server.py data`；HTTP 桥接：`POST /api/mcp`。

## 七、技术架构要点（一句话）

单 Agent + 工具（无多 Agent 框架）；千问只规划与解释、引擎只算数、服务层统一审计日志、
MCP 与 REST 共享同一业务服务；真实/历史/模拟数据三类来源全程标注；
离线演示与在线 Agent 共用同一套确定性引擎，降级路径不改变数字结果。
