# ChainCoxswain 数据字典（千问办公版）

## 一、引擎输入字段（物料）

| 字段 | 含义 | 缺失时的处理 |
|---|---|---|
| sku | 物料编码（A.zip 中为匿名 unit ID） | 必须有，否则该行忽略 |
| name | 物料名称 | 可为空 |
| stock | 库存快照数量 | 必须有 |
| usage | 日均用量（A.zip 按快照前 30 天历史消耗均值估计） | 0 表示无有效用量 |
| safety | 安全库存 | A.zip 未提供 → 引擎按 0（假设） |
| leadTime | 采购交期（天） | A.zip 未提供 → 引擎按 7 天（假设） |
| supplier | 供应商 | A.zip 未提供 → "未提供" |
| unitCost | 单价 | 可选 |

## 二、采购订单字段

| 字段 | 含义 |
|---|---|
| id | 采购单号（模拟单以 SIM-PO- 开头） |
| sku | 对应物料编码 |
| quantity | 数量 |
| arrival | 预计到货日期（YYYY-MM-DD，日初到货） |
| supplier | 供应商 |
| status | 已下单 / 计划 |

## 三、A.zip 数据集（真实历史数据）

| 文件 | 内容 | 用途 |
|---|---|---|
| inventory_info_A.csv | 632 行库存快照，唯一快照日 2021-03-01 | 物料起始库存 |
| use_train_A.csv | 2018-06-04 ~ 2021-03-01 逐日消耗（1002 天） | 估计日均用量（仅用快照前 30 天） |
| use_test_A.csv | 2021-03-02 ~ 2021-06-07 逐日消耗（98 天） | 仅用于回测评估，不参与参数估计（无泄漏） |
| product_topo_A.csv | product_level_1 → product_level_2 层级 | 产品分组 |
| geo_topo_A.csv | 地理 L1 → L2 → L3 层级 | 地理分组 |
| weight_A.csv | unit → 单件重量 | 辅助信息 |

**关键边界**：快照日是历史业务日期，必须原样保留，不得冒充实时库存；A.zip 没有采购订单、供应商、预计到货日期，相关功能要么提示缺失，要么使用明确标记 `simulated:true` 的模拟采购单。

## 四、场景类型枚举

| 值 | 含义 | 单位 |
|---|---|---|
| baseline | 基准（无扰动） | — |
| deliveryDelay | 最早一笔"已下单"采购单延期 | 天 |
| purchaseDelay | 最早一笔"计划"采购单下单推迟 | 天 |
| demandIncrease | 窗口内日均需求按比例上涨 | % |
| supplierOutage | 某供应商在途订单全部失效（仅手动/干预演示） | — |

## 五、仿真时序约定

1. 每日开始时，当天预计到货的采购单入库；
2. 当日消耗在入库后扣除；
3. 每日结束记录剩余库存（不为负，缺口单独累计）；
4. 逾期且未确认收货的采购单不计入未来到货；
5. 首次缺货日期 = 需求无法满足的第一天；临界点 = 首次触发缺货的最小整数扰动。
